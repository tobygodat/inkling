# Icon sources

Every icon is drawn in one colour, the theme's ink, so each file is used only as a shape.

| File | Source | Terms |
| --- | --- | --- |
| `settings.svg` | Lucide 1.43.0, `settings` (the cog) | ISC, `LICENSE-LUCIDE.txt` |
| `message-circle.svg` | Lucide 1.43.0, `message-circle` | ISC, `LICENSE-LUCIDE.txt` |
| `frame.svg` | Lucide 1.43.0, `frame` (the artboard) | ISC, `LICENSE-LUCIDE.txt` |
| `bot.svg` | Lucide 1.43.0, `bot` (the fallback provider icon) | ISC, `LICENSE-LUCIDE.txt` |
| `claude.svg` | Simple Icons 16.37.0, `claude` | CC0 1.0, `LICENSE-SIMPLE-ICONS.md` |
| `gemini.svg` | Simple Icons 16.37.0, `googlegemini` | CC0 1.0, `LICENSE-SIMPLE-ICONS.md` |

The Lucide files are byte for byte the ones GPUI Kit's `gpui-kit-assets` 0.9.1 carries in its full
catalog. The Simple Icons files are from `https://cdn.jsdelivr.net/npm/simple-icons@16.37.0/icons/`.
Simple Icons lists no separate licence or brand guidelines for either icon.

ChatGPT has no logo here. Simple Icons removed OpenAI's in v16.0.0 because OpenAI's brand page asks
for permission first (simple-icons/simple-icons#13944), so ChatGPT is drawn with `bot.svg`.

The logos are the providers' trademarks. They name the provider the writer chose, nothing more.
